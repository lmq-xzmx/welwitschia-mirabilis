# 项目介绍

## 1. 项目背景与目标

随着大数据时代的到来，企业面临数据量爆炸式增长、数据孤岛现象严重、数据开发效率低下等问题。传统的数据开发模式依赖大量手工编码和复杂配置，难以满足快速迭代和敏捷开发的需求。本项目旨在构建一个湖仓一体、存算分离、存储和计算配置化管理于一体的数据开发平台，通过低代码开发的特性，简化数据应用的构建过程，提升数据开发效率和质量。

项目目标是解决数据开发中的核心痛点，包括数据集成困难、存储计算耦合、开发周期长等问题，实现数据从采集到消费的全流程自动化和智能化管理。

## 2. 项目应用场景

系统适用于以下实际应用场景：

- **开源透明、伸缩部署**：开源免费，支持高可用和容器化部署，实现快速上线和弹性扩展。
- **打破数据孤岛**：解决数据跨平台难以被使用的问题，能够轻松集成已有的数据平台，实现了数据的共享和互通。
- **保护数据隐私**：支持私有化部署，私有云，IDC部署，具备社区最佳实践。
- **存算配置化管理**：支持存储和计算引擎的自定义配置，满足不同场景的数据开发需求。
- **多种数据源/计算引擎**：轻松对接各种主流数据库和计算引擎，实现了数据的无缝集成和共享。
- **多环境模式**：支持多环境开发，开发和生产数据严格分离，保障数据安全。

## 3. 核心功能概述

- **数据架构规划**：提供数据模型设计和架构规划工具，支持可视化建模。
- **数据源管理**：统一管理多种数据源，支持连接配置和元数据采集。
- **数据集成**：实现数据抽取、转换和加载（ETL）流程的配置化管理。
- **数据开发**：提供低代码数据处理和分析开发环境，支持SQL编辑和任务编排。
- **计算引擎**：集成多种计算引擎，支持任务调度和资源管理。
- **存储应用**：管理数据存储层，支持湖仓一体架构的数据存储和访问。
- **调度任务**：提供任务调度和监控功能，支持定时和事件触发。
- **运维发布**：支持应用的部署、监控和运维管理，确保系统稳定运行。

## 4. 主要技术栈

- **编程语言**：Java (后端), JavaScript (前端)
- **后端框架**：Spring Boot
- **前端框架**：React
- **数据库**：MySQL (元数据存储), ClickHouse/Hive (数据仓库)
- **中间件**：Kafka (消息队列), Redis (缓存)
- **算法或AI相关技术**：无

## 6. 项目使用指南

### 6.1 环境要求

- **操作系统**：Linux (推荐Ubuntu 18.04+), Windows 10+, macOS 10.15+
- **运行环境**：
  - JDK 8+
  - Node.js 14+
  - Docker (可选，用于容器化部署)
- **依赖组件**：
  - MySQL 5.7+
  - Redis 5.0+

### 6.2 启动步骤

```bash
# 1. 克隆项目
git clone <repository-url>
cd candelabratree

# 2. 安装后端依赖
# 使用Maven安装依赖
mvn clean install

# 3. 安装前端依赖
cd frontend
npm install
cd ..

# 4. 修改配置
# 编辑配置文件 application.yml，设置数据库连接、Redis等参数
# 示例：
# spring:
#   datasource:
#     url: jdbc:mysql://localhost:3306/candelabratree
#     username: <username>
#     password: <password>

# 5. 启动后端服务
mvn spring-boot:run

# 6. 启动前端服务
cd frontend
npm run start
```

### 6.3 访问地址

- **前端界面**：http://localhost:3000
- **后端API**：http://localhost:8080

### 6.4 默认账号说明

系统默认管理员账号：admin，密码：admin123。

生产环境部署时，请修改默认密码并使用强密码策略。

## 7. 典型使用流程

1. **登录系统**：使用默认或配置的账号登录平台。
2. **数据源配置**：在数据源管理模块添加和配置数据源连接。
3. **架构规划**：使用数据架构规划工具设计数据模型。
4. **数据集成**：配置ETL任务，实现数据抽取和加载。
5. **数据开发**：在开发环境中编写SQL或配置处理逻辑。
6. **任务调度**：设置调度规则，执行数据处理任务。
7. **存储管理**：管理数据存储和访问权限。
8. **运维监控**：查看任务运行状态和系统性能指标。
